# 参考文献人工核查清单与自动化脚本局限

[English](./how-to-verify-references.en.md) | 简体中文

AI 写作工具在生成学术段落时，经常构造“表面格式工整、实则不存在或张冠李戴”的参考文献：有的完全虚构标题与期刊，有的将真实论文的标题嫁接给错误的作者，有的把另一篇真实论文的 DOI 贴在编造条目后面。仅检查“格式是否合规”或“DOI 链接能否打开”，无法拦截这类错误。

本文提供一份不依赖付费工具的**五步人工核查清单**，并说明本仓库核查脚本（`tools/check_references.py`）的能力边界与技术取舍。

---

## 一、人工核查五步清单

### 第 1 步：拆解参考文献的四个核心核验项
把每条参考文献拆解为四个必须同时成立的要素，缺一不可：
1. **标题（Title）**：主标题与副标题措辞是否完整、未被同义改写。
2. **首作者及合作者（Authors）**：第一作者姓氏与署名顺序是否一致（警惕“真标题 + 假作者”或“领域知名学者 + 编造标题”）。
3. **出版年份与载体（Year & Venue）**：发表年份、期刊名称、会议论文集或出版社是否吻合。
4. **标识符（DOI / PMID / arXiv ID / ISBN）**：如条目附带标识符，记录其原始字符串以备反向核对。

### 第 2 步：有标识符时，先“反向解析”再逐项比对
如果参考文献包含 DOI、PMID 或 arXiv 编号：
- 直接访问 `https://doi.org/<DOI>`、PubMed 或 arXiv 页面，或查询 Crossref API（`https://api.crossref.org/works/<DOI>`）。
- **切勿只看网页能否返回 200 状态码**。必须核对解析出的落地页与引文文本是否属于**同一篇论文**：
  - 落地页标题是否与引文标题一致？（拦截“DOI 属于另一篇论文”的张冠李戴错误）
  - 落地页第一作者姓氏是否与引文第一作者一致？
  - 发表年份是否一致（允许在线发表 Online First 与正式卷期 Print 之间 ±1 年的常见出版差异，但需以引用版次为准）？
- 若 DOI 无法解析（404），不要立即判定整篇论文不存在，可能是 DOI 拼写损坏，继续执行第 3 步按标题检索。

### 第 3 步：无 DOI 文献，按“精确标题 + 首作者”多库交叉检索
大量真实文献本身没有 DOI（例如部分中文核心期刊论文、早期计算机会议如 NeurIPS/ICML/AAAI 论文、学术专著、学位论文、国家标准 GB/T 等）：
- **英文期刊/会议论文**：依次检索 [OpenAlex](https://openalex.org/)、[Crossref Metadata Search](https://search.crossref.org/)、DBLP（计算机领域）或 PubMed（生物医学领域）。检索时优先输入完整标题，核对返回结果的首作者与年份。
- **中文期刊/学位论文**：由于国际开放索引对中文文献收录不全，应在知网（CNKI）、万方、维普或国家哲学社会科学文献中心检索精确篇名与第一作者。
- **图书、章节与标准**：检索国家图书馆联机公共目录查询系统（OPAC）、WorldCat 或出版社官网目录，核对书名、作者/译者、版次与出版年。
- **警惕“标题轻微改写”**：如果搜索结果中只有作者和年份吻合、但标题存在若干实词替换（例如把 *Fabrication and errors in the bibliographic citations...* 改写为 *Hallucination and inaccuracies in bibliographic references...*），应判定为疑似 AI 改写，以数据库原始记录为准修正。

### 第 4 步：检查撤稿、勘误与预印本版本状态
即使论文真实存在且字段匹配，仍需确认其学术有效性：
- 在出版商页面、Crossref 更新记录（`update-to`）或 OpenAlex（`is_retracted`）中查看该文是否已被**撤稿（Retracted）**或发布重大关注声明（Expression of Concern）。已撤稿论文不应作为常规正面论据引用。
- 若引文指向 arXiv / bioRxiv 预印本，检查该文是否已在同行评审期刊或会议正式发表；若已正式发表，优先更新为正式出版版本的元数据，并统一对应的年份与卷期页码。

### 第 5 步：核对原文内容是否真正支撑正文论点
元数据核查通过仅代表“世界上存在这篇论文”，**不代表“这篇论文说过这句话”**：
- 打开原文摘要、结论或对应图表，确认其研究结论与你正文所引述的数据、方向一致（避免把持相反结论或无关背景的真实论文当作支撑证据）。

## 二、`tools/check_references.py` 脚本的局限与设计取舍

本仓库提供的命令行脚本 `tools/check_references.py` 仅使用 Python 标准库，通过 Crossref（核查含 DOI 条目）与 OpenAlex（检索无 DOI 条目）实现自动化初筛。在使用脚本结果时，请注意以下客观局限：

### 1. OpenAlex 与 Crossref 对中文文献、专著覆盖不全，且存在姓名拼音化差异
- **收录范围盲区**：OpenAlex 和 Crossref 主要覆盖国际英文期刊及部分开放获取/有 DOI 注册的中文期刊。相当比例的中文期刊论文、中文学术专著、国内会议集与行业标准未被收录，脚本对这类真实文献会返回 `not_found`。
- **中文作者署名语言不一致**：许多被 Crossref 或 OpenAlex 收录的中文论文，其元数据中的作者字段仅登记了拼音（如 `Wei Zhang` 或 `Zhang Wei`），而 GB/T 7714 引文文本写的是汉字（如 `张伟`）；反之亦然。纯标准库脚本不含汉字转拼音词典，在标题与年份匹配但作者脚本体系（汉字 vs 拉丁字母）不同时，可能无法直接比对姓氏，甚至报出 `mismatch (author)`。因此，中文文献的 `not_found` 与 `mismatch (author)` 均需结合国内数据库人工复核。

### 2. 标题相似度阈值（`difflib`）的精度与召回率权衡
脚本使用标准库 `difflib.SequenceMatcher` 对归一化后的标题（去除文献类型标志如 `[J]`/`[M]`、统一大小写与标点）计算字符级相似度：
- **阈值设得过高（如 `> 0.92`）**：会导致真实文献误报为 `mismatch` 或 `not_found`。例如引文省略了长副标题、存在全半角破折号/连字符差异、希腊字母转写差异（`β` vs `beta`）或大小写缩写差异。
- **阈值设得过低（如 `< 0.75`）**：会放过 AI 的“标题轻微改写”（如把几个关键词替换成近义词），或将标题高度模板化的不同论文（例如 *A Survey on Deep Learning for Medical Image Segmentation* 与另一篇仅差一两个词的综述）误判为同一篇。
- **当前折中策略**：脚本将候选召回下限设为 `0.60`（低于此值视为 `not_found`），将标题通过阈值设为 `0.85`（介于 `0.60` 到 `0.85` 之间会标记 `mismatch: title`，提示人工核对最近似候选）。在极端短标题或带有超长副标题的条目上，这一固定阈值仍可能出现误判。

### 3. 出版年份的合法跨年偏差
学术出版中常出现同一篇论文在不同数据源登记不同年份的情况：
- 期刊论文年末在线发表（Online First，如 2020 年 11 月）与次年正式分卷排期（Print，如 2021 年第 1 期）；
- 计算机会议（如 NeurIPS、ICLR、ACL）预印本发布年份与会议论文集出版年份相差 1 年，或历史会议论文在数年后集中补发 DOI 导致注册年份偏晚；
- 经典教材与专著的不同重印本或修订版年份不同。
脚本默认允许 `±1` 年的在线/纸质常见跨年容差或严格比对年份（具体视差异幅度报告 `mismatch: year`），遇到年份报错时需核查是否为版本差异。

### 4. 纯文本启发式解析（Regex）的边界
当输入不含结构化字段的纯文本参考文献列表时，脚本依靠正则表达式兼容 APA、GB/T 7714、Vancouver、IEEE 四种常见格式的作者、年份、引号/句点分隔标题与 DOI 提取：
- 若某条引文本身排版极不规范（例如缺失年份括号、作者与标题之间缺少句点分隔、标题内部包含多个问号或句号），启发式解析抽出的标题可能截断或混入期刊名，进而影响 OpenAlex 检索排序与 `difflib` 相似度得分。

### 5. 不具备撤稿深度判定与正文语义核验能力
本脚本聚焦于“不依赖 DOI 的存在性与基础元数据（标题、首作者、年份）核查”，不读取论文全文，也不判断该文献的实验结论是否支持你的正文论述。通过脚本初筛为 `verified` 的文献，在正式投稿前仍应完成人工核查清单中的第 4 步与第 5 步。
